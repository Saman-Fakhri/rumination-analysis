# rumination-analysis

Psychological data analysis project examining the relationship between self-esteem, optimism, and rumination using Python.

## Overview

This notebook recreates selected statistical analyses and visualizations from a prior university research project originally conducted in R. Because the original dataset was unavailable, synthetic data were generated to reproduce the analytical workflow and demonstrate statistical modeling, visualization, and interpretation techniques in psychological research.

## Analyses Included

- Descriptive statistics
- Correlation analysis
- Multiple linear regression
- Moderated regression analysis
- Interaction effect visualization
- Statistical data visualization

## Main Findings

- Higher self-esteem was associated with lower rumination.
- Higher optimism was also associated with lower rumination.
- Self-esteem emerged as the strongest predictor of rumination.
- Moderation analysis indicated that optimism did not significantly moderate the relationship between self-esteem and rumination.

## Project Purpose

This project was developed to demonstrate applied psychological data analysis, regression modeling, and scientific reporting using Python in a reproducible notebook format.
